# Voice-over script: 8 Italian phrases (40 s)

Each word card is on screen for 4 seconds. Pattern: **Italian (slowly) → Arabic → Italian again**.
🇮🇹 = say it in Italian, 🇸🇦 = say it in Arabic.

|---|---|---|

| 0:03–0:07 | Ciao | 🇮🇹 «Ciao» → 🇸🇦 «يعني مرحباً أو مع السلامة» → 🇮🇹 «Ciao!» |
| 0:07–0:11 | Buongiorno | 🇮🇹 «Buongiorno» → 🇸🇦 «صباح الخير» → 🇮🇹 «Buongiorno!» |

## Pronunciation reminders
- **Ciao** = تشاو (one syllable)
- **Grazie** = غراتسيه: the "z" sounds like "ts"
- **Scusi** = سكوزي: the "s" in the middle sounds like "z"
- **Quanto** = كوانتو, **costa** = كوستا
- **capisco** = كابيسكو: "sc" before "o" sounds like "sk"
- **bagno** = بانيو: "gn" sounds like «نْي»
- Stress: buon**GIOR**no, per fa**VO**re, ca**PIS**co

## How to record in TikTok
1. Upload `italian-8-phrases.mp4` → **Edit** → **Voiceover** (microphone icon).
2. Untick "Keep original sound" if you only want your voice. Otherwise keep it for the pops.
3. Record in one take while watching the cards, or in short takes: one per card.
4. **Volume** → original sound about 30%, voiceover 100%.
