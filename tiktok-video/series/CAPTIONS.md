# cinqueminuti: hook series (5 episodes)

Every episode: dark stickman style, British narrator, English captions with glowing key words,
Italian translation under every line. Two files each: `-voice.mp4` (narrator) and `-music.mp4` (no voice).
The hook is on screen in the very first frame. Pick that frame (or the one at ~1 s) as the TikTok cover.

## Ep. 1: Warning hook (`ep1-boring`)
**Hook:** "Never say this at a party in London." + bubble *"I'm so boring!"*
**Lesson:** boring ≠ bored, exciting ≠ excited (-ING ≠ -ED)
```
Non dire MAI questa frase a una festa a Londra 😬 "I'm so boring" ≠ "I'm so bored" 🇬🇧
#inglese #imparareinglese #ingleseperitaliani #erroriinglese #learnenglish #fyp
```

## Ep. 2: Challenge hook (`ep2-translate`)
**Hook:** "Translate this before the timer ends." + *"Ho fame."* + 3-second timer
**Lesson:** Ho fame / Ho ragione / Ho sonno → I'm hungry / I'm right / I'm sleepy
```
Traduci prima che finisca il tempo ⏱️ L'ultimo inganna tutti 😏 Scrivi il tuo punteggio 👇
#inglese #quizinglese #imparareinglese #ingleseperitaliani #sfida #fyp
```

## Ep. 3: Embarrassment hook (`ep3-hot`)
**Hook:** "Italians say this in summer, and the English laugh." + bubble *"I'm so hot!"*
**Lesson:** I'm hot (attraente) vs It's hot (fa caldo), plus I'm boiling
```
Gli italiani lo dicono ogni estate… e gli inglesi ridono 😳☀️ Tu lo dicevi?
#inglese #imparareinglese #ingleseperitaliani #figuracce #learnenglish #fyp
```

## Ep. 4: Identity hook (`ep4-native`)
**Hook:** "You speak English like a textbook. Natives don't."
**Lesson:** Can you repeat? → Sorry? · I have understood → Got it · I'm fine, thank you, and you? → Not bad, you? · Goodbye → See you!
```
Parli inglese come un libro di scuola? 📖 Ecco come parlano davvero gli inglesi 🇬🇧 Quale usi ancora? 👇
#inglese #ingleseparlato #imparareinglese #ingleseperitaliani #madrelingua #fyp
```

## Ep. 5: Stakes hook (`ep5-pub`)
**Hook:** "Say this in a British pub, and the barman stares at you." + bubble *"Give me a beer."*
**Lesson:** Can I get a pint, please? · 1 pint = 568 ml · Cheers = thanks
```
Dillo in un pub inglese e il barista ti fissa 😐🍺 Come si ordina davvero una birra a Londra
#inglese #londra #pub #imparareinglese #ingleseperitaliani #fyp
```

## Posting plan
One episode a day, in this order: 2 → 1 → 3 → 5 → 4. The challenge first, because it gets the most comments.
After 2–3 days, check **TikTok Studio → Analytics → Retention** and tell Claude which hook kept people longest.
More episodes in that hook style can then be built quickly with `make_episode.py`.
